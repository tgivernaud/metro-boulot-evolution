# Assets 3D

Le workflow GitHub Actions télécharge les modèles glTF depuis KhronosGroup/glTF-Sample-Assets avant l'import Godot :
- CesiumMan (personnage animé)
- ToyCar (voitures)
- Lantern (éclairage décoratif)

Ces modèles ne constituent pas encore un pack artistique cohérent définitif. Ils sont utilisés comme éléments 3D de validation du pipeline.

La licence de chaque asset doit être contrôlée avant toute distribution publique. Le pipeline ne télécharge que les modèles nécessaires au build, et les inclut dans l'export généré.

Source : https://github.com/KhronosGroup/glTF-Sample-Assets
