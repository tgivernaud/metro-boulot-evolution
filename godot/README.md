# Métro, Boulot, Évolution — nouveau projet Godot

Projet natif Godot 4, séparé du prototype HTML historique situé à la racine du dépôt.

## État actuel
Première base de jeu : quartier 3D procédural, contrôles tactiles, caméra à la troisième personne, collisions, quatre lieux interactifs, courte boucle de mission, argent/énergie, sauvegarde locale. **Ce n'est pas encore une application iPhone compilée ni un jeu terminé.** Les personnages et bâtiments sont des modèles provisoires ; la direction artistique finale nécessite des assets 3D cohérents et des animations.

## Utilisation
Ouvrir le dossier `godot` dans Godot 4.3 ou version compatible et lancer la scène principale. Le projet est conçu pour évoluer vers un export iOS. Les builds iOS nécessitent macOS/Xcode et une signature appropriée.

## Suite
1. Faire valider le projet par le moteur Godot et corriger toute erreur de parsing.
2. Importer un pack de modèles 3D cohérent sous licence vérifiée.
3. Remplacer le personnage par un modèle animé avec AnimationTree.
4. Tester les contrôles et performances sur iPhone.
5. Mettre en place compilation iOS distante et distribution, sans abonnement supplémentaire tant qu'une option gratuite suffisante n'a pas été vérifiée.

Aucun service payant ni crédit d'agent n'est utilisé par ces fichiers.
